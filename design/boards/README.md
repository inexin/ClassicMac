# Board specs

One file per board on the design canvas, written so an implementer can work without opening the canvas. Colours and sizes are named by token (see [../TOKENS.md](../TOKENS.md)); a hex value here is only for Mac content, which keeps its own colours. Sample data in the boards (names, sizes, messages) is illustrative.

Screenshots of the boards can be dropped next to these files as `<name>.png`; the spec text wins where they differ.
