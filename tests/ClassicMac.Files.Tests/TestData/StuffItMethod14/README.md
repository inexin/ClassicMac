# StuffIt method 14 vectors

These hand-built feature vectors exercise method-14 block framing, direct and recursively encoded Huffman code lengths,
length/distance codes with extra bits, the zero-initialized history window, multiple blocks, and data/resource fork
dispatch. Expected output is asserted in `StuffItFeatureTests.cs`. They are protocol vectors and are not archives
produced by StuffIt Installer Maker.
