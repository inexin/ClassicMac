# StuffIt method 15 corpus vectors

`StuffItDeluxe651.sit` is `testfile.stuffit651_dlx.mac9.sit` from the CC0
[StuffIt test file corpus](https://github.com/ssokolow/stuffit-test-files). It was created by StuffIt Deluxe 6.5.1
for Mac OS 9. The `testfile.PICT` data fork uses method 15 and expands to `ExpectedPicture.pict`. `Test Image` has a
method-15 resource fork which expands to `ExpectedPictureResource.bin`. `Test Image` has a method-15 resource fork
which expands to `ExpectedTestImageResource.bin`. The expected resource forks were extracted from the corpus's
AppleDouble sidecars. The other archive members are kept as part of the end-to-end container fixture. The source corpus
and its contents are public domain;
see the upstream [license](https://github.com/ssokolow/stuffit-test-files/blob/master/LICENSE.cc0).
